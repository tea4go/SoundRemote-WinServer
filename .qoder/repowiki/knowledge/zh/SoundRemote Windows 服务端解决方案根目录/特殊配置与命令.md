本地需安装 Visual Studio 2022 并勾选「使用 C++ 的桌面开发」工作负载；常用命令：
- `./run_win.ps1 -Check` 检测环境
- `./run_win.ps1 -InstallDeps` 安装 nuget + vcpkg 依赖
- `./run_win.ps1 -Build -Configuration Release -Platform x64` 构建
- `./run_win.ps1 -Run` 停止旧进程并启动最新构建
- `./run_win.ps1 -Test` 运行 Tests.exe
- CI 触发条件为 push/pull_request 至 main 分支。
