本模块为 C++/MSBuild 解决方案根，由 `SoundRemote.sln`（VS 17.7+）聚合两个 vcxproj：`SoundRemote`（主程序）和 `Tests`（基于 gmock 的单元测试），在 Debug/Release × x64/Win32 四种组合下统一构建。
- 依赖管理采用 vcpkg-tool 新配置格式：`vcpkg.json` 声明 boost-asio、boost-json、simpleini、opus 四个库，`vcpkg-configuration.json` 通过 git baseline + microsoft artifact registry 锁定版本；NuGet 包 gmock.1.11.0 用于测试框架。
- 本地入口 `run_win.ps1` 以 PowerShell 函数封装环境初始化（`Initialize-VsEnvironment` 通过 vswhere + DevShell 自动定位 VS 2022 并注入 VCTargetsPath），并通过 `-Check/-InstallDeps/-Build/-Run/-Test` 开关复用同一入口完成不同阶段；输出默认位于 `<Platform>\<Configuration>\`，可通过 `-Output` 覆盖。
- CI 使用 `.github/workflows/build.yml`，在 windows-latest 上经 `microsoft/setup-msbuild@v2` + `TAServers/vcpkg-cache@v3` 缓存 vcpkg 二进制加速构建，最终上传 `bin\SoundRemote.exe` 作为 artifact。
- 辅助脚本 `run_win.bat` / `run_win.ps1` 提供一键启动入口，会先终止旧进程再启动新实例。
